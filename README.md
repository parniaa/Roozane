# Roozane — Marketing Website

Official marketing site for **Roozane (Persian Calendar)** — iOS app.

- `index.html` — landing page (hero, features, screens, privacy strip, download)
- `privacy.html` — privacy policy (use this URL in App Store Connect)

- `script.js` — scroll reveals, phone tilt, nav
